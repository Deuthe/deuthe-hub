Deuthe's Solution

Instalador automático de WSA + Dofus Touch Multi-Account para Windows 11. Todo en un solo ejecutable. Sin configuración manual.

Descargar DeutheSetup.exe

~700 MB · Windows 11 · Requiere clave de activación

Cómo Instalar

1

Descargar el Instalador

Haz clic en el botón de arriba para descargar DeutheSetup.exe. La descarga puede tardar unos minutos dependiendo de tu conexión.

2

Crear una Carpeta Dedicada

Crea una carpeta en tu PC, por ejemplo C:\DeutheSetup o en el Escritorio. Mueve el archivo DeutheSetup.exe dentro de esa carpeta.

⚠️ Importante: No ejecutes el .exe directamente desde la carpeta de Descargas. Siempre ponlo en su propia carpeta primero.
3

Ejecutar como Administrador

Haz clic derecho en DeutheSetup.exe → Ejecutar como administrador. Ingresa la contraseña de autorización proporcionada.

4

Seleccionar Cuentas y Esperar

Elige el número de cuentas que deseas (1-8) y pulsa START INSTALLATION. El instalador se encarga del resto automáticamente. Si pide reiniciar, reinicia y vuelve a ejecutar.

5

¡Listo! Abre tus Cuentas

Busca DOFUS Touch, DOFUS Touch W, DOFUS Touch Y, etc. en el menú Inicio de Windows. Cada icono es una cuenta independiente.

Preguntas Frecuentes

¿Cuántas cuentas puedo tener abiertas al mismo tiempo? ▼
Hasta 4 cuentas simultáneas con la misma conexión de internet. Para PvM es más que suficiente para jugar cómodamente.
¿Es seguro? ¿Qué hace el instalador? ▼
El instalador configura WSA (Windows Subsystem for Android), instala el juego original y crea copias con nombres de paquete diferentes para que puedan coexistir. No modifica archivos del sistema ni envía datos a ningún servidor externo. Al cerrar, se eliminan todos los archivos temporales automáticamente.
¿Necesito reiniciar el PC? ▼
Solo si es la primera vez que instalas WSA. El instalador activará la "Virtual Machine Platform" de Windows y pedirá un reinicio. Después del reinicio, ejecuta el instalador de nuevo y continuará desde donde se quedó.
Me da error de autorización al abrir la segunda cuenta ▼
Asegúrate de tener Google Chrome instalado dentro de WSA. Sin Chrome, los clones comparten el mismo token de autenticación y se cierran entre sí. Instala Chrome desde el Play Store de WSA o contacta para asistencia.
¿Dónde debo poner el archivo .exe? ▼
Crea una carpeta específica (ej: C:\DeutheSetup o una carpeta en el Escritorio) y coloca el .exe ahí. No lo ejecutes directamente desde la carpeta de Descargas, ya que necesita espacio para extraer archivos temporales durante la instalación.

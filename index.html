Project Zero-Cost: Enterprise iSCSI SAN

Designing, implementing, and evaluating a block-level storage network using consumer-grade hardware.

Author: Kevin Guzman

Executive Summary

In modern enterprise infrastructure, Storage Area Networks (SANs) are the standard for high-performance virtualization. This research demonstrates the validation of a fully functional iSCSI SAN using exclusively consumer-grade hardware.

Key Result: The iSCSI implementation delivered ~900% higher random read IOPS compared to a traditional SMB NAS configuration on identical hardware.

1. Context & Problem

While Network Attached Storage (NAS) systems are common in home labs, they operate at the file level (SMB/NFS). This introduces overhead that makes them suboptimal for VM hosting or databases.

My mentors challenged me: "A NAS is fine for Semester 4. If you want to show readiness for the real world, build a SAN."

2. Infrastructure Design

The architecture utilizes a dedicated VLAN to isolate storage traffic, ensuring security and performance.

Device Role IP Address
Intel NUC (i5) iSCSI Target 192.168.2.200
Windows 11 PC Initiator (Client) 192.168.2.201
Netgear GS105E Managed Switch 192.168.2.4

3. Implementation (CLI)

Configuration was performed using the Linux IO (LIO) stack via targetcli.

# Create the backstore (file-based)
/backstores/fileio create name=sanlun0 file_or_dev=/san/lun0.img size=100G

# Create the iSCSI Target
/iscsi create iqn.2025-11.nl.fontys:san

# Set CHAP Security (Unidirectional)
/iscsi/iqn.../tpg1 set auth userid=kevin password=KevinPass12

4. Benchmark Results

Performance was measured using CrystalDiskMark (Queues: 32, Threads: 1). The Random 4K Read test highlights the massive advantage of block-level storage.

Metric iSCSI SAN SMB NAS Difference
Seq. Read 117 MB/s 117 MB/s 0% (Tie)
Random Read 4K 101.51 MB/s 11.25 MB/s +900%
Random Write 4K 0.16 MB/s 9.05 MB/s -98%

5. Conclusion

This project successfully proves that enterprise-grade storage behavior can be simulated on zero-cost hardware. By utilizing iSCSI, I achieved significant latency reduction for read-heavy workloads, validating the technology's use in virtualization environments.
